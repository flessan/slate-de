SLATE-DE
Features Architecture GitHub Support

The CLI-First Wayland Compositor.

A pane-based, scriptable desktop environment built in Rust. Everything is a command. Everything is searchable.

curl -sSf https://slate.dotfiles.qzz.io/install.sh | bash

Command-Centric

Unified command registry for window management, system control, and vision analysis.

WASM Plugins

Low-latency extensions via Wasmtime. Script your DE in any language targeting WebAssembly.

Vision-Aware

Integrated OCR and object detection. Query the text content of any application surface.

TUI Native

Render Ratatui frames directly to Wayland SHM buffers. Zero terminal overhead.

Modular by Design

core/       - Reactive state & node graph
compositor/ - Smithay-powered Wayland server
renderer/   - High-perf TUI pipeline
vision/     - Local & Cloud OCR providers
plugins/    - WASM sandboxed runtime
